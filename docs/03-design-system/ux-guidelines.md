# Diretrizes de UX

- linguagem clara;
- ações destrutivas diferenciadas;
- feedback imediato;
- formulários longos por etapas;
- autosave apenas com indicador;
- filtros persistentes quando útil;
- tabelas responsivas;
- atalhos para usuários frequentes;
- operações móveis com poucos toques;
- status com texto, não apenas cor;
- datas e valores no padrão local;
- confirmação de ações críticas.
