# Prompt de bootstrap para Claude Code

Use este texto após copiar a documentação para o repositório:

> Leia `README.md`, `CLAUDE.md` e toda a pasta `docs`, começando por `docs/README.md`. Não implemente ainda. Faça uma análise da arquitetura proposta, identifique decisões pendentes, dependências entre módulos, riscos de multi-tenancy e um plano de bootstrap do monorepo. Depois proponha a estrutura inicial de diretórios, os pacotes, scripts, ferramentas e as primeiras ADRs. Respeite o monólito modular, o white-label e o isolamento por tenant. Não crie código específico para a Fogueira Caminhões.
