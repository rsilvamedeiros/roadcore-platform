# Arquivos e documentos

## Categorias

- imagens públicas;
- documentos privados;
- comprovantes;
- notas;
- contratos;
- CNH e certificados;
- anexos de manutenção;
- comprovantes de entrega.

## Regras

- metadados no banco;
- conteúdo em storage;
- namespace por tenant;
- URL assinada;
- controle de acesso;
- antivírus quando aplicável;
- limite de tipo e tamanho;
- retenção;
- checksum;
- versionamento para documentos críticos.
