# Segurança

## Controles

- autenticação segura;
- MFA para perfis privilegiados;
- sessões revogáveis;
- hashing adequado;
- segredo em cofre;
- validação de entrada;
- rate limiting;
- headers de segurança;
- CORS restrito;
- proteção de upload;
- criptografia em trânsito;
- backups;
- auditoria;
- menor privilégio.

## LGPD

Mapear:

- dados pessoais;
- finalidade;
- base legal;
- retenção;
- compartilhamento;
- exportação;
- anonimização;
- exclusão quando aplicável;
- incidentes.
