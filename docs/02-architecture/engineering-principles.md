# Princípios de engenharia

1. Domínio antes da tela.
2. Configuração antes de fork.
3. Contratos explícitos.
4. Dependências apontam para dentro.
5. Tenant sempre presente no contexto.
6. Autorização no servidor.
7. Auditoria para ações críticas.
8. Idempotência em efeitos externos.
9. Observabilidade desde o início.
10. Evolução incremental.
11. Sem abstração sem caso real.
12. Sem dependência nova sem avaliação.
13. Estado derivado não deve ser duplicado sem necessidade.
14. Dados históricos não devem ser reescritos silenciosamente.
15. Interfaces devem tratar estados vazios, erro e carregamento.
16. Acessibilidade é requisito.
17. Testes focam risco e regra.
18. Migrações devem ser reversíveis ou possuir plano de recuperação.
19. Dados sensíveis devem ter retenção e acesso controlados.
20. Documentação acompanha decisão.
