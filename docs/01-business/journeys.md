# Jornadas principais

## Compra de veículo
Busca → anúncio → contato → lead → oportunidade → proposta → análise → troca/financiamento → fechamento → entrega.

## Contratação de frete
Solicitação → qualificação → cotação → aceite → ordem → planejamento → coleta → trânsito → entrega → comprovação → faturamento.

## Viagem
Ordem → composição → motorista → checklist → adiantamento → saída → despesas → ocorrências → entrega → retorno → acerto.

## Manutenção
Alerta/ocorrência → triagem → OS → orçamento → aprovação → execução → peças → teste → liberação → custo.

## Comissão
Regra vigente → evento gerador → cálculo → revisão → desconto/adiantamento → aprovação → pagamento → histórico.
