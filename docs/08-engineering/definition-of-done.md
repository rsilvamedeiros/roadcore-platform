# Definition of Done

- requisito atendido;
- permissão validada;
- tenant isolado;
- estados de UX tratados;
- testes adequados;
- lint e tipos aprovados;
- auditoria avaliada;
- observabilidade avaliada;
- documentação atualizada;
- migração segura;
- acessibilidade revisada;
- sem segredo;
- revisão concluída.
