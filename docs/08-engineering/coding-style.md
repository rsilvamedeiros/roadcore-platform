# Estilo de código

- código (identificadores, comentários, mensagens de commit, textos de log técnico) em inglês; documentação e conteúdo de negócio continuam em português;
- termos de domínio sem tradução óbvia seguem `docs/00-overview/glossary.md` como fonte da verdade;
- TypeScript strict;
- nomes descritivos;
- funções pequenas;
- evitar `any`;
- evitar booleanos ambíguos;
- usar tipos de valor;
- comentários explicam motivo;
- módulos exportam API pública;
- tratamento de erro explícito;
- nenhuma regra crítica apenas em validação visual.
