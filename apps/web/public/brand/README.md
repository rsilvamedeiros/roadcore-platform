# RoadCore brand assets

- `roadcore-horizontal.svg`: primary signature for light backgrounds.
- `roadcore-horizontal-light.svg`: reversed signature for dark backgrounds.
- `roadcore-symbol.svg`: compact mark for avatars, app icons and social profiles.
- `roadcore-monochrome.svg`: one-color-friendly signature for documents and restricted printing.

Keep the clear space around the signature at least equal to half the symbol width. Do not recolor, stretch or rotate the supplied artwork.
